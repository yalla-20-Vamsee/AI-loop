# AI loop

A minimal interactive AI loop in Python.

Usage:
- Install dependencies: `pip install -r requirements.txt`
- Run with local fallback AI: `python ai_loop.py`
- Run with OpenAI (requires OPENAI_API_KEY): `export OPENAI_API_KEY="sk..." && python ai_loop.py --openai`

The script will prompt you for input and print responses until you type `exit` or `quit`.
